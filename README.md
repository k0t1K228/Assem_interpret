# УВМ: ассемблер и интерпретатор (вариант 21)

## Общее описание
Учебная виртуальная машина (УВМ) с раздельной памятью команд и данных.
Проект включает ассемблер (CSV → двоичный файл) и интерпретатор.
Язык реализации: Python 3.

## Структура
- `src/uvm/` — исходный код;
- `tests/` — тесты;
- `examples/` — примеры программ на ассемблере.

## Язык ассемблера
Формат CSV: одна команда в строке, `мнемоника,операнд1,операнд2,...`.
Операнды записываются в порядке полей спецификации. Допустимы
десятичные и `0x`-числа. Пустые строки и строки с `#` игнорируются.

| Команда | Операнды | Описание |
|---|---|---|
| `load` | B, C | регистр B ← константа C |
| `read` | B, C, D | регистр D ← память[регистр B + смещение C] |
| `write` | B, C, D | память[регистр B + смещение D] ← регистр C |
| `abs` | B, C | регистр C ← abs(память[адрес B]) |

Пример:

```csv
load,23,985
read,4,490,111
```

## Сборка и запуск
Запуск тестов:

```bash
make test
```

Запуск ассемблера:

```bash
PYTHONPATH=src python -m uvm.asm_cli examples/spec_tests.csv out/spec.bin --test
```

Аргументы: путь к CSV-программе, путь к двоичному файлу (каталог
создаётся автоматически), флаг `--test`. Ассемблер записывает файл и
выводит его размер в байтах. В режиме `--test` дополнительно печатаются
байты каждой команды. Команды хранятся в порядке little-endian.

Ожидаемый вывод:

```
Размер двоичного файла: 18 байт
0xFD, 0x92, 0x3D, 0x00
0x90, 0xA0, 0xFE, 0x0D
0xA2, 0xB3, 0x48, 0x03
0x29, 0x66, 0x00, 0x00, 0xC0, 0x02
```
