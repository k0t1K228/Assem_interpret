# УВМ: ассемблер и интерпретатор (вариант 21)

## Общее описание
Учебная виртуальная машина (УВМ) с раздельной памятью команд и данных.
Проект включает ассемблер (CSV → двоичный файл) и интерпретатор.
Язык реализации: Python 3.

## Структура
- `src/uvm/` — исходный код;
- `tests/` — тесты;
- `examples/` — примеры программ на ассемблере.

## Язык ассемблера
Формат CSV: одна команда в строке, `мнемоника,операнд1,операнд2,...`.
Операнды записываются в порядке полей спецификации. Допустимы
десятичные и `0x`-числа. Пустые строки и строки с `#` игнорируются.

| Команда | Операнды | Описание |
|---|---|---|
| `load` | B, C | регистр B ← знаковая константа C (−131072…131071) |
| `read` | B, C, D | регистр D ← память[регистр B + смещение C] |
| `write` | B, C, D | память[регистр B + смещение D] ← регистр C |
| `abs` | B, C | регистр C ← abs(память[адрес B]) |

Пример:

```csv
load,23,985
read,4,490,111
```

## Сборка и запуск
Запуск тестов:

```bash
make test
```

Запуск ассемблера:

```bash
PYTHONPATH=src python -m uvm.asm_cli examples/spec_tests.csv out/spec.bin --test
```

Аргументы: путь к CSV-программе, путь к двоичному файлу (каталог
создаётся автоматически), флаг `--test`. Ассемблер записывает файл и
выводит его размер в байтах. В режиме `--test` дополнительно печатаются
байты каждой команды. Команды хранятся в порядке little-endian.

Ожидаемый вывод:

```
Размер двоичного файла: 18 байт
0xFD, 0x92, 0x3D, 0x00
0x90, 0xA0, 0xFE, 0x0D
0xA2, 0xB3, 0x48, 0x03
0x29, 0x66, 0x00, 0x00, 0xC0, 0x02
```

## Интерпретатор
Модель УВМ: память команд (байты бинарного файла) и память данных
(65536 ячеек) **разделены**; есть 128 регистров. Реализованы команды
`load`, `read` и `write`.

Запуск:

```bash
PYTHONPATH=src python -m uvm.interp_cli out/copy.bin out/dump.csv 10 24
```

Аргументы: бинарная программа, файл дампа (CSV), первый и последний
адреса дампа (границы включены). Формат дампа: заголовок
`address,value`, затем строки `адрес,значение`.

## Пример: копирование массива
Программа `examples/copy_array.csv` записывает числа 11, 22, 33, 44, 55
по адресам 10–14 и копирует их на адреса 20–24:

```bash
PYTHONPATH=src python -m uvm.asm_cli examples/copy_array.csv out/copy.bin
PYTHONPATH=src python -m uvm.interp_cli out/copy.bin out/copy_dump.csv 10 24
cat out/copy_dump.csv
```

## АЛУ: команда abs
Команда `abs,B,C` читает ячейку памяти данных по адресу B, берёт её
модуль и кладёт в регистр C. Чтобы в памяти можно было получить
отрицательные числа, константа `load` знаковая.

Пример `examples/abs_demo.csv`: числа -7, 25, -1000 по адресам 30–32,
их модули записываются по адресам 40–42:

```bash
PYTHONPATH=src python -m uvm.asm_cli examples/abs_demo.csv out/abs.bin
PYTHONPATH=src python -m uvm.interp_cli out/abs.bin out/abs_dump.csv 30 42
cat out/abs_dump.csv
```

## Тестовая задача: abs() над вектором длины 8
Программа записывает исходный вектор по адресам 10–17 и записывает
`abs()` каждого элемента в **новый** вектор по адресам 20–27.
Программы генерируются скриптом `scripts/gen_vector_abs.py`
(8 чисел → CSV-программа), готовые лежат в `examples/`:

| Файл | Данные |
|---|---|
| `vector_abs.csv` | -5 12 -300 0 77 -1 100000 -131072 |
| `vector_abs_negative.csv` | только отрицательные |
| `vector_abs_positive.csv` | только неотрицательные |
| `vector_abs_limits.csv` | граничные значения константы |

Новая программа:

```bash
python scripts/gen_vector_abs.py examples/my.csv 1 -2 3 -4 5 -6 7 -8
```

Запуск всех примеров и просмотр дампа:

```bash
for name in vector_abs vector_abs_negative vector_abs_positive \
    vector_abs_limits; do
  PYTHONPATH=src python -m uvm.asm_cli examples/$name.csv out/$name.bin
  PYTHONPATH=src python -m uvm.interp_cli out/$name.bin \
      out/$name.dump.csv 10 27
done
column -s, -t out/vector_abs.dump.csv
```

В дампе адреса 10–17 содержат исходный вектор, 18–19 пусты, а
20–27 содержат результат `abs()`.
