# УВМ: ассемблер и интерпретатор (вариант 21)

## Общее описание
Учебная виртуальная машина (УВМ) с 4 командами. Проект состоит из:
- **ассемблера** — переводит программу на языке ассемблера (формат CSV)
  в двоичный файл;
- **интерпретатора** — выполняет двоичный файл и сохраняет дамп
  памяти данных в CSV.

Особенности варианта: память команд и память данных разделены,
команды имеют размер 4 или 6 байт, порядок байтов — little-endian.
Язык реализации: Python 3.9+, только стандартная библиотека.

## Структура репозитория
```
src/uvm/    исходный код (ассемблер, интерпретатор)
tests/      модульные тесты
examples/   программы на языке ассемблера
scripts/    генератор программ abs() над вектором
Makefile    запуск тестов и демонстрации
```

## Система команд
Поля нумеруются от младшего бита. Номера битов включительно.

| Команда | A (код) | Размер | Поля |
|---|---|---|---|
| `load` | 29 | 4 байта | B: 5–11 (регистр), C: 12–29 (знаковая константа) |
| `read` | 16 | 4 байта | B: 5–11 (регистр с адресом), C: 12–20 (смещение), D: 21–27 (регистр-результат) |
| `write` | 2 | 4 байта | B: 5–11 (регистр с адресом), C: 12–18 (регистр-источник), D: 19–27 (смещение) |
| `abs` | 9 | 6 байт | B: 5–36 (адрес в памяти), C: 37–43 (регистр-результат) |

Поле A занимает биты 0–4 во всех командах.

## Язык ассемблера (CSV)
Одна команда в строке: `мнемоника,операнд1,операнд2,...`. Операнды
идут в порядке полей (B, C, D). Допустимы десятичные числа и числа
с префиксом `0x`. Пустые строки и строки, начинающиеся с `#`,
пропускаются.

| Команда | Операнды | Действие |
|---|---|---|
| `load,B,C` | B — регистр, C — константа −131072…131071 | регистр B ← C |
| `read,B,C,D` | B — регистр, C — смещение 0…511, D — регистр | регистр D ← память[регистр B + C] |
| `write,B,C,D` | B — регистр, C — регистр, D — смещение 0…511 | память[регистр B + D] ← регистр C |
| `abs,B,C` | B — адрес памяти, C — регистр | регистр C ← abs(память[B]) |

Номера регистров: 0…127. Значения вне диапазона поля, неизвестные
команды и неверное число операндов приводят к ошибке с номером строки.

## Ассемблер
```bash
PYTHONPATH=src python -m uvm.asm_cli <программа.csv> <выход.bin> [--test]
```
- `программа.csv` — исходный текст на языке ассемблера;
- `выход.bin` — двоичный файл-результат (каталог создаётся сам);
- `--test` — режим тестирования: дополнительно печатает байты каждой
  команды в виде `0xFD, 0x92, 0x3D, 0x00`.

Ассемблер печатает размер двоичного файла в байтах. Код возврата:
0 — успех, 1 — ошибка (сообщение в stderr).

## Интерпретатор
```bash
PYTHONPATH=src python -m uvm.interp_cli <программа.bin> <дамп.csv> <первый> <последний>
```
- `программа.bin` — результат работы ассемблера;
- `дамп.csv` — файл дампа памяти данных;
- `первый`, `последний` — диапазон адресов дампа, границы включены.

Формат дампа: заголовок `address,value`, затем строки
`адрес,значение`. Интерпретатор печатает число выполненных команд.

Модель УВМ: память команд — байты бинарного файла (только чтение),
память данных — 65536 ячеек (изначально нули), 128 регистров.
Память команд и данных разделены. Обращение к адресу вне памяти
данных и неизвестный код операции — ошибка.

## Описание модулей и функций
| Модуль | Содержимое |
|---|---|
| `isa.py` | описание команд: `Field`, `CommandSpec`, `COMMANDS`, `BY_MNEMONIC`, `BY_OPCODE`, `bit_mask` |
| `assembler.py` | `parse_program` (CSV → список команд), `parse_row`, `parse_operand`, `value_range`, `is_skipped`, `format_instruction`, `Instruction`, `AsmError` |
| `encoder.py` | `encode_instruction` (команда → байты), `assemble`, `format_bytes` |
| `asm_cli.py` | консольный ассемблер: `main`, `build_parser`, `load_program`, `write_binary` |
| `errors.py` | `VmError`, `DecodeError` |
| `decoder.py` | `decode_instruction` (байты → команда), `extract_field` |
| `vm.py` | `Machine` (`read_data`, `write_data`, `step`, `run`), операции `op_load`, `op_read`, `op_write`, `op_abs`, `OPERATIONS`, `check_address`, `check_range`, `write_dump` |
| `interp_cli.py` | консольный интерпретатор: `main`, `build_parser` |
| `scripts/gen_vector_abs.py` | генератор программы abs() над вектором из 8 чисел |

## Настройки
Отдельных файлов настроек нет, параметры — константы в коде:

| Константа | Файл | Значение |
|---|---|---|
| `REGISTER_COUNT` | `vm.py` | 128 регистров |
| `DATA_MEMORY_SIZE` | `vm.py` | 65536 ячеек памяти данных |
| `BYTE_ORDER` | `isa.py` | little-endian |
| `SOURCE_BASE`, `RESULT_BASE` | `scripts/gen_vector_abs.py` | адреса 10 и 20 |

## Сборка и тесты
Сборка не требуется. Тесты (`unittest`):

```bash
make test
```

Демонстрация (ассемблер в режиме тестирования, затем вектор):

```bash
make demo
```

Проверка стиля (необязательно): `flake8`, `radon`, `pep8-naming`.

## Примеры использования
### Тесты из спецификации
```bash
PYTHONPATH=src python -m uvm.asm_cli examples/spec_tests.csv out/spec.bin --test
```
```
Размер двоичного файла: 18 байт
0xFD, 0x92, 0x3D, 0x00
0x90, 0xA0, 0xFE, 0x0D
0xA2, 0xB3, 0x48, 0x03
0x29, 0x66, 0x00, 0x00, 0xC0, 0x02
```

### Копирование массива
`examples/copy_array.csv` записывает числа 11, 22, 33, 44, 55 по
адресам 10–14 и копирует их на адреса 20–24:

```bash
PYTHONPATH=src python -m uvm.asm_cli examples/copy_array.csv out/copy.bin
PYTHONPATH=src python -m uvm.interp_cli out/copy.bin out/copy.dump.csv 10 24
```

### Команда abs
`examples/abs_demo.csv`: числа −7, 25, −1000 по адресам 30–32,
их модули записываются по адресам 40–42:

```bash
PYTHONPATH=src python -m uvm.asm_cli examples/abs_demo.csv out/abs.bin
PYTHONPATH=src python -m uvm.interp_cli out/abs.bin out/abs.dump.csv 30 42
```

### Тестовая задача: abs() над вектором длины 8
Исходный вектор лежит по адресам 10–17, результат `abs()` записывается
в новый вектор по адресам 20–27. Программы создаёт генератор:

```bash
python scripts/gen_vector_abs.py examples/my.csv 1 -2 3 -4 5 -6 7 -8
```

Готовые программы в `examples/`:

| Файл | Данные |
|---|---|
| `vector_abs.csv` | -5 12 -300 0 77 -1 100000 -131072 |
| `vector_abs_negative.csv` | только отрицательные |
| `vector_abs_positive.csv` | только неотрицательные |
| `vector_abs_limits.csv` | граничные значения константы |

Запуск и дамп основной программы:

```bash
PYTHONPATH=src python -m uvm.asm_cli examples/vector_abs.csv out/vector_abs.bin
PYTHONPATH=src python -m uvm.interp_cli out/vector_abs.bin out/vector_abs.dump.csv 10 27
cat out/vector_abs.dump.csv
```

Дамп: адреса 10–17 — исходный вектор
`-5 12 -300 0 77 -1 100000 -131072`, 18–19 пусты, адреса 20–27 —
результат `5 12 300 0 77 1 100000 131072`.
